# le Renard · landing page

Landing page de la bêta du Renard (nom de travail) : l'onboarding guidé par le Renard.

## Modifier le site

- Tout le contenu est dans `index.html`. Les images sont dans `images/`.
- Chaque modification poussée sur la branche `main` est mise en ligne automatiquement par GitHub Pages en une à deux minutes.

## À compléter avant d'ouvrir le site au public

- [ ] Formulaire : remplacer `VOTRE_ID` par l'identifiant Formspree (`https://formspree.io/f/...`).
- [ ] Remplacer `contact@votre-domaine.fr` par la vraie adresse de contact.
- [ ] Mentions légales : adresse postale, directeur de la publication, hébergeur (GitHub, Inc.).
- [ ] Politique de confidentialité : date de mise à jour, prestataires et encadrement des transferts hors UE.
